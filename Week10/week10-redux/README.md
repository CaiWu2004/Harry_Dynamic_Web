## Week 10

My final project will improve my midterm recipe app so users can browse recipes, use the recipe forms, and save recipes to a personal library. The library of saved recipes should live in Redux because multiple parts of the app may need to show or update it; temporary form inputs should use `useState`, and props should pass recipe information to child components. I do not currently need Context, but I could add it later if several parts of the app need to share a setting, such as a theme.

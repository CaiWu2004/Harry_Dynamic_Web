# Recipe Library

## What this app is for

This App is used for recording and organising recipes you like and would be interested in making. You would basiclly input or submit a form with the recipe name, ingreditents, steps, and time and it will be save into the library which you can access anytime.

## User story

As a college student I tend to grow tired of the same meals over and over again offered the the schools cafetaria. However, I am also someone who don't really know what to cook most of the time. I was wondering if only I had a place where I can store all the recipes I found online or cooked before in one place and access it anytime it would be nice.

## How to run it

To run this so far I would need to open a server and as well as host this app locally before I can use it.
